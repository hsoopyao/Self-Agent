以下基于当前 v1.1.1 代码，仅列举建议，未修改任何代码。

## 一、优先优化项

### P0：建议优先处理

1. **启动速度优化**
    - `app.py` 启动时会立即加载向量库和 Embedding 模型，首次启动较慢。
    - 建议改为按需加载，并增加“模型加载中/加载失败”状态提示。

2. **路径统一**
    - `chroma_db`、`data`、日志目录依赖当前工作目录。
    - 从不同目录启动时可能找不到文件，建议统一使用项目根目录的绝对路径。

3. **路由逻辑优化**
    - 当前通常需要先调用一次路由 LLM，再调用实际聊天或 ReAct LLM。
    - 可针对电影、天气、知识库等高频场景增加确定性规则，减少一次模型请求和误路由。

4. **ReAct 步数和工具调用控制**
    - 增加可视化的最大步数配置。
    - 为不同任务设置不同预算。
    - 对每个工具设置最大调用次数。
    - 工具观察结果使用结构化摘要，避免原始 JSON 截断导致重复查询。

5. **429 / 1305 错误处理**
    - 对模型繁忙、超时、API Key 缺失、联网失败分别提示。
    - 增加指数退避和可选备用模型。
    - 避免用户只能看到“请稍后重试”。

6. **聊天状态管理**
    - 将用户消息、最终回答、思考、工具调用、观察结果拆成独立事件。
    - 避免 Streamlit rerun 时出现灰色重复内容、动态占位符残留或历史污染。

### P1：体验和准确性优化

7. **RAG 检索质量**
    - 增加关键词检索与向量检索结合。
    - 增加重排序模型。
    - 支持查询改写和多问题拆分。
    - 调整检索阈值时提供测试问题和命中结果预览。

8. **RAG 来源引用**
    - 回答中显示文件名、页码、匹配片段。
    - 支持点击来源后查看原文片段，而不是只显示文件名。

9. **文档去重和增量索引**
    - 使用文件哈希判断重复文档。
    - 文档更新时只重新索引变化部分。
    - 删除文档时避免同名文件相互影响。

10. **上下文压缩优化**
    - 压缩时优先保留最近一轮、用户偏好和未完成任务。
    - 工具调用过程不全部塞入长期上下文。
    - 压缩失败时保留原始历史，避免丢失对话。

11. **日志系统完善**
    - 将项目中的 `print` 统一替换为日志。
    - 增加日志轮转和级别配置。
    - 避免记录 API Key、完整用户隐私和过长工具结果。

12. **设置持久化**
    - 当前设置主要保存在 Streamlit 会话中。
    - 重启后模型、阈值等配置可能恢复默认值。
    - 可保存到本地 JSON、SQLite 或 `.env`。

13. **深色模式适配**
    - 使用 CSS 变量统一管理颜色。
    - 检查思考、工具调用、观察卡片在深色模式下的文字对比度。
    - 增加字体大小和无障碍显示选项。

14. **路径和文档说明同步**
    - README 中的项目结构与实际文件名存在部分不一致，例如 `components.py` / `ui_components.py`、`chat.py` / `chats.py`。
    - 建议统一文档描述。

15. **测试体系**
    - 增加 JSON 解析、路由、ReAct 步数、工具参数解析、RAG 阈值测试。
    - 使用 Mock 工具测试，不依赖真实 API。
    - 增加启动自检命令。

## 二、可以新增的功能

### 对个人使用最有价值

1. **多会话管理**
    - 新建、重命名、删除、归档会话。
    - 每个会话独立保存上下文和临时文件。

2. **聊天记录保存与导出**
    - 保存到 SQLite 或 JSON。
    - 支持导出 Markdown、TXT、JSON。
    - 支持恢复历史会话。

3. **重新生成和停止回答**
    - 增加“重新生成”按钮。
    - 增加“停止生成”按钮。
    - 支持编辑上一条问题后重新回答。

4. **回答复制和引用**
    - 一键复制回答。
    - 复制时保留或去除 Markdown 格式。
    - RAG 回答附带来源文件和页码。

5. **联网开关**
    - 增加“仅本地知识库”模式。
    - 每次联网前显示确认。
    - 明确展示本次回答使用了本地资料、网络还是猫眼工具。

6. **模型配置档案**
    - 保存“快速模型”“高质量模型”“低成本模型”等配置。
    - 支持备用模型自动切换。

### 知识库功能

7. **更多文件格式**
    - DOCX、XLSX、CSV、网页、图片 OCR。
    - 支持拖拽上传多个文件。

8. **知识库分类**
    - 按项目、工作、学习、个人资料分类。
    - 支持标签和单独检索某一分类。

9. **知识库问答调试面板**
    - 显示命中文档、相似度、检索片段和最终上下文。
    - 方便调整 Embedding、切片长度和阈值。

### ReAct 和工具功能

10. **ReAct 过程控制**
    - 显示/隐藏思考过程。
    - 显示当前步骤、剩余步骤和耗时。
    - 支持手动停止工具调用。
    - 支持限制可用工具。

11. **工具调用历史**
    - 保存每次工具名称、参数、耗时、结果和错误。
    - 支持单独重试某一步工具。

12. **猫眼功能增强**
    - 支持日期选择。
    - 支持定位附近影院。
    - 按距离、价格、评分筛选。
    - 提供购票链接。
    - 缓存短时间内重复的影院和排片查询。

13. **搜索结果缓存**
    - 对天气、影院、新闻等结果设置短时间缓存。
    - 减少 API 调用和响应时间。

### 个人助手方向

14. **语音输入和语音朗读**
    - 语音转文字。
    - 回答朗读。
    - 适合移动端或免手操作。

15. **个人信息记忆**
    - 保存用户偏好、常用城市、常用影院等。
    - 提供“查看和删除记忆”功能。

16. **个人提醒和日报**
    - 天气提醒。
    - 电影排片提醒。
    - 每日新闻或知识库摘要。

17. **本地隐私保护**
    - 一键清除聊天记录和临时文件。
    - 本地历史加密。
    - 启动时检查 `.env` 是否被误提交到 Git。

## 三、个人开发建议优先顺序

1. 路由和 ReAct 调用次数优化
2. 429 / 超时错误提示和备用模型
3. 多会话与聊天记录保存
4. RAG 来源引用和检索调试
5. 文档去重、分类和增量索引
6. 猫眼日期筛选与购票链接
7. 语音输入、提醒和日报功能
