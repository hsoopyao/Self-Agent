## v1.0.0 (2026-08-25)
* 新增 ReAct 多步推理：支持复杂问题的自主思考与工具调用循环
* 新增可视化设置页面：所有调优参数可通过 UI 调整
* 新增 Token 实时监控：主界面顶部显示 Token 用量，自动触发历史压缩
* 新增多文件临时上传：支持同时上传最多 3 个文件
* 优化 ReAct 触发逻辑：仅对 rag 和 web 意图生效，避免闲聊误触
* 优化观察结果展示：自动生成摘要，出处以可点击链接形式展示
* 优化 UI 样式：思考、行动、观察过程以不同样式分块显示
* 优化上下文管理：动态 Token 计数 + 智能历史压缩
* 修复：内容安全过滤错误的友好提示
* 修复：ReAct JSON 解析容错增强

## v1.1.1 (2026-08-28)

### 优化一：聊天链路、联网搜索与 ReAct 稳定性

- [x] 将 Tavily 搜索从线程池伪超时改为客户端原生 HTTP 超时，默认 5 秒，可通过 `TAVILY_SEARCH_TIMEOUT` 调整。
- [x] ReAct 执行发生异常后立即结束，避免同一个错误重复调用五次并再次输出“超出最大思考步数”。
- [x] 在统一的 LLM 工厂中增加请求超时和重试策略：`LLM_REQUEST_TIMEOUT` 默认 60 秒，`LLM_MAX_RETRIES` 默认 2 次。
- [x] 普通聊天、联网聊天、RAG 和上下文摘要统一按实际请求创建 LLM，设置页切换模型后下一次调用立即生效。
- [x] 内部知识库未命中时不再自动将问题发送给 Tavily；只有用户明确写出“联网搜索”等授权词才允许外部搜索。
- [x] ReAct 增加提示层和工具执行层两层联网授权检查，未授权时阻止 `web_search` 执行。
- [x] 移除 ReAct 逐字符 `sleep` 的假流式输出，最终答案改为单块输出，减少额外等待和页面重绘。

### 优化二：修复聊天页面灰色重复文字

- [x] 修复每次提交新问题时，上一轮回答以灰色文字重复显示的问题。
- [x] 原因是上一轮动态流式输出占位符在下一次长时间 rerun 期间被 Streamlit 暂时保留。
- [x] 回答保存完成后立即执行一次短 rerun，将动态占位符转换为稳定历史消息；不会重复保存用户问题或助手回答。

### 已知问题与后续优化

- [ ] 智谱模型繁忙时可能返回 `429 / 1305`。后续可增加专用友好提示、指数退避和可选备用模型；当前统一重试策略不能保证在服务持续拥堵时成功。
