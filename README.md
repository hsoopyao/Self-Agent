# 🤖 Self Agent — 智能文档问答助手

一个基于 **LangChain + ChromaDB + BGE Embedding + GLM-4.7-Flash** 构建的本地化智能助手，支持**内部知识库检索（RAG）**、**实时联网搜索**和**ReAct 多步推理**，并提供友好的 Streamlit Web 界面。

---

## ✨ 核心功能

- 📚 **文档管理**  
  支持上传 `PDF` / `TXT` / `MD` 文件，自动切分、向量化并存入本地 ChromaDB，构建专属知识库。

- 🧠 **智能检索（RAG）**  
  基于 BGE 向量模型，对用户问题进行语义检索，精准匹配内部文档片段，并生成高质量回答。

- 🌐 **联网搜索**  
  集成 tavily 搜索引擎，可实时获取最新资讯、新闻、天气、股票等动态信息。

- 🔁 **ReAct 多步推理**  
  针对复杂问题（如“对比”、“分析”、“为什么”），自动进入“思考→行动→观察→思考”循环，调用多个工具综合回答。

- 💬 **多轮对话上下文管理**  
  支持多轮对话，自动进行 Token 计数和动态历史压缩，确保不超出模型上下文窗口。

- 🎨 **流式输出与可视化思考过程**  
  思考、工具调用、观察结果以不同样式分块显示，最终答案逐字输出，体验流畅。

- 📊 **Token 实时监控**  
  实时显示当前会话 Token 用量，接近上限时自动触发历史摘要压缩，并提示用户等待。

- ⚙️ **可视化设置**  
  提供独立的设置页面，用户可通过 UI 调整检索阈值、Token 上限、压缩比例、ReAct 触发关键词和模型名称，无需修改代码。

- 💻 **需求分析**

  将文档中的需求进行分析可视化并支持导出Excel格式。

## 🧭 使用指南
### 主界面（聊天）
* 顶部导航栏可在 “聊天” ， “知识库”，“需求分析”和 “设置” 页面间切换。
* 侧边栏： 
  * 清空上下文窗口：重置当前会话历史。 
  * Token 实时显示：查看当前会话 Token 使用情况，超过阈值会触发上下文压缩机制。 
  * 知识库资料：实时展示知识库中的所有文档，供用户选择询问。
  * 当前配置：展示当前生效的所有调优参数。
* 输入框：输入问题后回车，系统自动路由并生成回答。

### 知识库管理页面（文档管理）
* 上传文档：支持 PDF/TXT/MD，点击“导入文档”后自动切分向量化。
* 已导入文档列表：可查看文件名，点击 🗑️ 删除。
* 支持文件分组。

### 需求分析（文档分析）
* 根据知识库中的文件进行选择，并做分析需求缓存。
* 多次分析保存历史记录，并可做对比。
* 分析输出需求列表，并支持在线编辑，且支持导出CSV格式文件。

### 设置页面（配置调优）
所有可调参数集中在此页面，包括：
* 全局 RAG 检索阈值：控制内部知识库匹配的敏感度。
* 最大上下文 Token 数：超过此值将触发历史压缩。
* 压缩目标比例：压缩后 Token 降至 最大Token * 此比例。
* ReAct 触发关键词：当问题包含这些词时自动启用多步推理。
* ReAct 最大思考步数：限制单个问题最多执行的模型决策次数，猫眼排片等多步查询建议设置为 10。
* 模型名称：切换智谱 BigModel 系列模型（需账户权限）。

调整后点击“保存设置”立即生效，无需重启应用。

### 路由与推理模式
* 简单问题（问候、天气、常识）→ 直接路由至闲聊或搜索。
* 内部知识问题（公司政策、技术手册）→ RAG 检索回答。
* 复杂推理问题（包含“对比”、“分析”、“为什么”等）→ 自动进入 ReAct 多步推理：
  1. 💭 思考：分析问题，决定下一步行动
  2. 🔧 行动：调用工具（内部检索或联网搜索）
  3. 📊 观察：获取结果摘要，并标注可点击的出处链接
  4. 循环直到收集足够信息，生成最终答案

## ⚙️ 配置调优
所有关键参数均可通过 设置页面 进行可视化调整，无需编辑代码文件。

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 全局 RAG 检索阈值 | 内部知识库匹配敏感度 | 0.5 |
| 临时文件检索阈值 | 会话临时文件匹配敏感度 | 0.3 |
| 最大上下文 Token 数 | 触发历史压缩的阈值 | 6000 |
| 压缩目标比例 | 压缩后 Token 降至 最大Token × 此比例 | 0.6 |
| ReAct 最大思考步数 | 单个问题最多执行的模型决策次数 | 10 |
| ReAct 触发关键词 | 启用多步推理的关键词列表 | 对比,分析,为什么,总结,评价,比较,区别,影响,解析,解读,解释,研究 |
| 模型名称 | 智谱 BigModel 系列模型 | glm-4.7-flash |
